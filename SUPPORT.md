# Support for 2.5.1

## Non-sensitive problems

After the owner publishes the official repository, use its **Issues** tab for reproducible, non-sensitive defects or documentation problems. Include:

- version `2.5.1` and whether you used the web or Windows package;
- browser and operating-system name/version;
- the scenario and screen where the problem occurred;
- concise reproduction steps, expected result and observed result;
- the SHA-256 of the ZIP if the Windows asset is involved.

Do not attach exported runs unless you have inspected them and deliberately choose to share them. Remove personal information, usernames, local file paths and unrelated logs.

## Security and privacy

Do not put vulnerability details in a public issue. Follow [`SECURITY.md`](SECURITY.md) and use GitHub private vulnerability reporting.

For questions about local game data, read [`PRIVACY.md`](PRIVACY.md). Do not post personal or confidential data publicly.

## Support boundary

Physical iPhone/iPad Safari and Android Chrome were not tested for 2.5.1. The project can accept defect reports from those devices, but this release makes no physical-device support claim. The educational model is not a forecasting or operational decision service.

Before publication, return non-sensitive feedback to the project owner through the existing project channel. No public account, email address or response time is invented in this dossier.
