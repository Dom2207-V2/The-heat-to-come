# Privacy notice for The Heat to Come 2.5.1

Documentation revision: 26 September 2026. Local release dossier; online publication has not been performed.

This notice describes the behaviour of the compiled game and distinguishes device-local records from the technical data processed by GitHub when it hosts the repository, Release files and Pages site.

## Data handled by the game

The game requires no account and asks for no name, e-mail address, student number or free-text profile. It contains no advertising, analytics, tracking pixel, remote telemetry, social login or payment service.

The game stores the following records locally in the browser, with session or in-memory fallback where persistent storage is unavailable:

- audio, motion, sensory-intensity and tutorial preferences;
- the planning draft, current run and completed-run archive, including scenario, random seed, interventions, events, choices, metrics and score;
- an optional local playtest trace, only when the user deliberately enables that feature.

These records are used to operate, resume and review the game. They are not automatically sent to the repository owner, an educational institution or another service. The score evaluates a simulated game, not the person playing it.

## Exports and imports

JSON and XLSX files are read or created only after the user chooses an import or export command. Exported files remain under the control of the user and anyone with whom the user shares them. Instructors and researchers who ask participants to submit exports are responsible for providing their own appropriate notice and lawful basis.

## Retention and deletion

Local records remain until the user clears the site's browser data, deletes the relevant browser profile or the browser removes them. Session and memory fallbacks may end when the page or session closes. Exported files must be deleted separately from the device or sharing service where they were saved.

The repository owner cannot read or delete records that exist only in the user's browser.

## GitHub hosting data

GitHub is the planned host for the repository, Release downloads and GitHub Pages site. These statements apply when those services are used. When those services are accessed, GitHub may process technical and usage data such as IP address, requested URL, date and time, browser or device information, referring page, response and security logs under the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

The game code does not set cookies. Cookies or similar technologies added by the hosting platform, GitHub account state or browser environment are governed by GitHub's notices and settings, not by the game code.

## External requests

All game JavaScript, CSS, image, font and audio assets are bundled locally. Qualification detected no application request to an external analytics, advertising, font, map, login, telemetry or payment service. Links in documentation or compiled diagnostic strings are not requested automatically.

## Questions and sensitive information

For questions about the game's local-data behaviour, use a non-sensitive repository issue or the contact method shown on the publishing GitHub account's profile. Do not post personal data in an issue. Security matters must follow [`SECURITY.md`](SECURITY.md).

This product is designed primarily for higher education. Any organised study involving participants, collection of exports, assessment or use with minors requires a separate privacy and ethics assessment by the organiser.
