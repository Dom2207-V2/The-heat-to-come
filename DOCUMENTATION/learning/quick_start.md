# Quick start

Formats: Markdown, PDF and DOCX. Author: G2 teaching/manuals specialist; independent review is recorded in the dossier inventory.

## Begin

Open the 2.5.0 game provided by your facilitator. No account is required. This guide starts at the game home screen; the delivery package will provide its own launch instructions. It does not assume that a public site or a Windows download already exists.

1. Select **Begin a new game**. If there is existing progress, export it before confirming replacement. Select **Continue your run** instead if you wish to resume it.
2. Complete the short orientation, or choose **Skip orientation**. You can also open it from **How it works** on the home screen.
3. Select a campus and choose **Enter the Task Force briefing**. Read the starting conditions, mission objectives and constraints, then select **Join the Task Force**.
4. Open intervention cards. Read their purpose, timing, benefit and trade-off. Select an available **Start L1** or **Start L2** action; later turns can also offer **Upgrade** or contextual **Repair**. Check current and planned states, cost, remaining resources and coordination pressure.
5. Choose **Review commitment**. Remove an action or select **Edit portfolio** if necessary. When ready, choose **Commit & reveal event**. The committed decision cannot be edited after reveal.
6. Read the event. When it offers a decision, choose a response and select **Confirm response**. Read the event explanation and whole-turn outcome, then continue to the next turn. Repeat through turn 3 and select **Open the debrief**.

## Read the result and keep a copy

Read the campus trajectory and explanations alongside the score. Lower risk is better; higher resilience, continuity and acceptability are better. The score is a reflection aid, not a grade or real-world forecast.

Open **Advanced settings** and select **Export XLSX** or **Export JSON** to download the current run. Keep the untouched export if you intend to import it later. For a local pause, use **Save & exit**; if the planning prompt appears, choose **Save and leave**. Resume in the same browser profile and at the same game address with **Continue your run**.

Local storage is not a cloud backup. If a storage warning appears, export before closing. A run export does not preserve the separate, uncommitted planning draft. Save that draft locally or record those selections separately. Historical saves cannot be migrated into 2.5.0.

## If you get stuck

Use **Clear filters** if cards are missing. An unavailable operation shows its reason beside the control. The game remains playable without sound; use **Experience settings** for sound and motion preferences. See the player guide for map controls, imports, replay and troubleshooting.
